Build a complete responsive web application called WardSpace.

WardSpace is a simple, positive, non-clinical ward companion designed for people staying on an inpatient mental health ward and the staff supporting them.

The purpose is to reduce boredom, improve access to everyday ward information, make activities easier to discover, allow patients to suggest things they would like to do, and reduce repetitive non-clinical questions for staff.

This is a prototype/MVP and MUST NOT behave as a clinical system.

Core safety rule

WardSpace must NOT:

* provide medical advice
* give medication advice
* diagnose mental health conditions
* assess suicide or self-harm risk
* make clinical recommendations
* determine whether someone is safe
* replace communication with clinical staff
* store NHS numbers
* store diagnoses
* store medication records
* store identifiable health information
* claim that submitted requests are monitored for emergencies

Where appropriate, display a short message such as:

WardSpace is for everyday ward information and activities only. If you need medical help, feel unsafe, or need urgent assistance, speak directly to a member of staff.

Do not make this message frightening or overly prominent. It should simply be clear.

TECHNOLOGY

Use a modern but simple stack suitable for Replit.

Preferred stack:

* React
* TypeScript
* Tailwind CSS
* Node.js / Express backend
* SQLite for the MVP
* REST API
* Lucide icons if available

Structure the project properly with separate frontend, backend, components, pages, services and database code.

Do not build an unnecessarily complicated architecture.

The application should work immediately when launched in Replit.

Make it responsive for:

* mobile phones
* tablets
* laptops
* shared ward touchscreen displays

Design mobile-first.

DESIGN STYLE

The visual style should feel:

* calm
* modern
* friendly
* uncluttered
* accessible
* mature rather than childish
* welcoming without looking overtly medical

Avoid stereotypical mental-health imagery.

Do not fill the interface with hearts, brains, medical crosses or inspirational quotes.

Use:

* large readable typography
* rounded cards
* generous spacing
* large touch targets
* clear icons
* simple navigation
* subtle shadows
* accessible contrast
* clear button states

Avoid excessive animation.

The app should feel similar to a high-quality modern public-service application combined with a simple community noticeboard.

Use a soft neutral colour palette with a restrained accent colour.

Include light mode.

Prepare the CSS structure so dark mode could be added later, but dark mode is not required for the MVP.

Accessibility is important.

Implement:

* semantic HTML
* keyboard navigation
* visible focus states
* ARIA labels where appropriate
* large buttons
* readable font sizes
* adequate contrast
* screen-reader friendly forms
* clear validation errors

Avoid tiny text.

Touch targets should ideally be around 44px or larger.
